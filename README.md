# SQL Essential Training – my exercises

SQL queries I wrote while completing the **SQL Essential Training** course on LinkedIn Learning (07/2026).

All queries run against **WSDA_Music**, a sample SQLite database of a digital music store (customers, invoices, employees, tracks, artists). I worked in DB Browser for SQLite.

## What's inside

| File | Topics |
|---|---|
| [01_select_basics.sql](01_select_basics.sql) | `SELECT`, aliases, `ORDER BY`, `LIMIT`, `WHERE`, `CASE` |
| [02_joins.sql](02_joins.sql) | `INNER JOIN` across two and three tables |
| [03_functions_aggregates.sql](03_functions_aggregates.sql) | String and date functions, `SUM`, `AVG`, `COUNT`, `GROUP BY`, `HAVING` |
| [04_subqueries_views_dml.sql](04_subqueries_views_dml.sql) | Subqueries, `IN` / `NOT IN`, views, `INSERT`, `UPDATE`, `DELETE` |
